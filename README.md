# Vesta

Project structure:
- `frontend/`: Expo React Native app
- `backend/`: Express API server

Run locally:
- Frontend install from repo root: `npm run frontend:install`
- Frontend from repo root: `npm run frontend:start`
- Backend install from repo root: `npm run backend:install`
- Backend from repo root: `npm run backend:start`

Run inside each app:
- Frontend: `cd frontend` then `npm start`
- Backend: `cd backend` then `npm start`
